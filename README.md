# TechCare Solutions Ltd. – IT Helpdesk System

## Project Overview
This project demonstrates the deployment and configuration of an IT helpdesk system using Zammad.

The system was developed as a practical IT support and DevOps project for a fictional company, TechCare Solutions Ltd.

## Technologies Used
- AWS EC2
- Ubuntu Linux
- Zammad
- Elasticsearch
- Nginx
- Git and GitHub

## Key Features
- IT support ticket management
- Ticket assignment to support agents
- Department-based support groups
- Customer and agent accounts
- Ticket status and priority management
- Customer communication through ticket replies

## Departments
- IT Support
- Human Resources (HR)

## Project Structure
- screenshots/ – Application screenshots
- scripts/ – Installation and configuration scripts
- documentation/ – Deployment documentation

## Learning Outcomes
- Linux server administration
- AWS EC2 deployment
- Helpdesk application configuration
- Service and process management
- Basic Git and GitHub workflow
